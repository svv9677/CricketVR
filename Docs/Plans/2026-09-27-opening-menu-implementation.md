# Opening Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Splash the game's front door with a vibrant main menu (Quick Match, Practice in Nets, Settings), and add a pause menu to CricketVR and Nets, with every piece built as a reusable prefab.

**Architecture:** One `MenuRoot` prefab hosts a push/pop stack of `MenuScreen` prefabs (`MainMenuScreen`, `PauseScreen`, `SettingsScreen`). A new static `GameSettings` class over `PlayerPrefs` becomes the single thing the settings UI edits; `Main` subscribes and applies. Prefabs are generated by editor tools, following the existing `UIPrefabBuilder` pattern — nothing is created at runtime.

**Tech Stack:** Unity 6000.3.24f1, C#, uGUI world-space canvases, TextMeshPro, Unity Input System + OpenXR, NUnit EditMode tests.

**Design spec:** [`Docs/Plans/2026-09-27-opening-menu-design.md`](2026-09-27-opening-menu-design.md)

## Conventions for this codebase

Read these before Task 1. They are not obvious and getting them wrong causes rework.

**No runtime construction.** Every panel is a prefab built by an editor menu item under
`Tools/CricketVR/`, with control handlers wired as *persistent* listeners via
`UnityEditor.Events.UnityEventTools.AddPersistentListener`. Runtime code never calls
`AddComponent` for UI or `onClick.AddListener`. See `Assets/Editor/UIPrefabBuilder.cs`.

**Styling goes through `UIStyle`.** Never hardcode a colour or size in a builder. Use
`UIStyle.Card`, `UIStyle.Accent`, `UIStyle.Control`, etc. Panels are 1 canvas px = 1 mm.

**Building blocks.** `WorldPanelBuilder` has the canvas, card, rows/columns and text.
`UIControls` has buttons, segmented controls and sliders. Reuse them; do not write new
primitives unless this plan says to.

**Fake-null.** In editor code, a missing component compares as a "fake null" that `??` does not
catch. Use `TryGetComponent`, as `WorldPanelBuilder.MakeCard` does.

**No assembly definitions.** All runtime code compiles into `Assembly-CSharp`, all of
`Assets/Editor/**` into `Assembly-CSharp-Editor`. Runtime files must never reference
`UnityEditor`. Task 1 builds the harness that proves this.

**Commits.** The repo owner makes commits himself. Each task below ends with a "stage and
report" step, not a `git commit`. Do not run `git commit` unless explicitly asked.

```python
#!/usr/bin/env python3
"""Player-view Roslyn compile: every runtime .cs under Assets, WITHOUT UnityEditor.dll.

Reproduces what a Quest player build sees, so editor-only API leaking into runtime
code fails here instead of at build time. Editor scripts (Assets/**/Editor/**) and
test folders are excluded, since they are allowed to use UnityEditor.

Usage: python3 Tools/verify_compile.py [--unity <editor Contents dir>]
Exit code 0 = clean.
"""
import argparse
import os
import subprocess
import sys
import tempfile

DOTNET = ("/Applications/Unity/Hub/Editor/6000.3.24f1/Unity.app/Contents"
          "/Resources/Scripting/NetCoreRuntime/dotnet")
DEFAULT_UNITY = "/Applications/Unity/Hub/Editor/6000.3.24f1/Unity.app/Contents"
PROJECT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))


def collect_sources(root):
    """Every runtime .cs: skips Editor and Tests folders."""
    out = []
    for base, dirs, files in os.walk(root):
        dirs[:] = [d for d in dirs if d not in ("Editor", "Tests")]
        for f in files:
            if f.endswith(".cs"):
                out.append(os.path.join(base, f))
    return sorted(out)


def collect_refs(unity):
    scripting = os.path.join(unity, "Resources", "Scripting")
    refs = []
    # netstandard 2.1 ref profile ONLY - mixing mscorlib with these produces
    # hundreds of spurious CS0012 errors.
    ns = os.path.join(scripting, "NetStandard", "ref", "2.1.0")
    for f in os.listdir(ns):
        if f.endswith(".dll"):
            refs.append(os.path.join(ns, f))
    managed = os.path.join(scripting, "Managed")
    for base, _dirs, files in os.walk(managed):
        for f in files:
            # UnityEditor.dll deliberately excluded: this is the player view.
            if f.endswith(".dll") and not f.startswith("UnityEditor"):
                refs.append(os.path.join(base, f))
    # Package assemblies (Input System, XR, TextMeshPro, ...) as precompiled DLLs.
    pkgdir = os.path.join(PROJECT, "Library", "ScriptAssemblies")
    if os.path.isdir(pkgdir):
        for f in os.listdir(pkgdir):
            # Skip assemblies whose sources we compile ourselves, or csc sees
            # every Oculus type twice and reports CS0121 ambiguity.
            if f.endswith(".dll") and not f.startswith("Assembly-CSharp") \
                    and not f.startswith("Oculus") and "Editor" not in f:
                refs.append(os.path.join(pkgdir, f))
    return refs


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--unity", default=DEFAULT_UNITY)
    args = ap.parse_args()

    csc = os.path.join(args.unity, "Resources", "Scripting", "DotNetSdkRoslyn", "csc.dll")
    if not os.path.exists(csc):
        sys.exit(f"csc.dll not found at {csc} - pass --unity <editor Contents dir>")

    sources = collect_sources(os.path.join(PROJECT, "Assets"))
    refs = collect_refs(args.unity)
    print(f"{len(sources)} sources, {len(refs)} references")

    defines = ";".join(
        [f"UNITY_{y}_{m}_OR_NEWER" for y in range(2018, 2024) for m in range(1, 5)]
        + [f"UNITY_{y}_OR_NEWER" for y in range(2018, 2024)]
        + ["UNITY_6000_0_OR_NEWER", "UNITY_6000_3_OR_NEWER",
           "UNITY_ANDROID", "ENABLE_VR", "UNITY_XR_MANAGEMENT"])

    # Response file with every path quoted: several contain spaces.
    with tempfile.NamedTemporaryFile("w", suffix=".rsp", delete=False) as rsp:
        rsp.write("-target:library\n-nostdlib+\n-noconfig\n")
        rsp.write("-out:" + os.path.join(tempfile.gettempdir(), "playerview.dll") + "\n")
        rsp.write(f"-define:{defines}\n")
        for r in refs:
            rsp.write(f'-r:"{r}"\n')
        for s in sources:
            rsp.write(f'"{s}"\n')
        path = rsp.name

    proc = subprocess.run([DOTNET, csc, f"@{path}"], capture_output=True, text=True)
    os.unlink(path)
    errors = [l for l in (proc.stdout + proc.stderr).splitlines() if ": error " in l]
    for line in errors[:40]:
        print(line)
    print(f"\n{len(errors)} errors")
    return 1 if errors else 0


if __name__ == "__main__":
    sys.exit(main())
```

Create `Tools/scan_guids.py`:

```python
#!/usr/bin/env python3
"""Scan every scene/prefab/asset for m_Script GUIDs that no longer resolve.

A clean compile does NOT prove serialized references still resolve - a renamed or
deleted script leaves prefabs pointing at nothing, and Unity reports it only as a
silent "missing script" in the inspector.

Baseline: this project has 4 known pre-existing dangling GUIDs. A run is clean when
the count is still 4 and the list is unchanged.

Usage: python3 Tools/scan_guids.py
"""
import os
import re
import sys

PROJECT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
GUID_IN_META = re.compile(r"^guid:\s*([0-9a-f]{32})", re.M)
SCRIPT_REF = re.compile(r"m_Script:\s*\{fileID:\s*-?\d+,\s*guid:\s*([0-9a-f]{32})")
ASSET_EXT = (".unity", ".prefab", ".asset", ".controller", ".playable")


def known_guids():
    """Every script/DLL GUID that exists, from Assets and the package cache."""
    found = set()
    roots = [os.path.join(PROJECT, "Assets"),
             os.path.join(PROJECT, "Library", "PackageCache")]
    for root in roots:
        for base, _dirs, files in os.walk(root):
            for f in files:
                if f.endswith(".cs.meta") or f.endswith(".dll.meta"):
                    p = os.path.join(base, f)
                    try:
                        text = open(p, encoding="utf-8", errors="ignore").read()
                    except OSError:
                        continue
                    m = GUID_IN_META.search(text)
                    if m:
                        found.add(m.group(1))
    return found


def main():
    have = known_guids()
    print(f"{len(have)} script/DLL GUIDs known")
    dangling = {}
    assets = os.path.join(PROJECT, "Assets")
    # Single pass: a per-file grep loop times out on this project.
    for base, _dirs, files in os.walk(assets):
        for f in files:
            if not f.endswith(ASSET_EXT):
                continue
            p = os.path.join(base, f)
            try:
                text = open(p, encoding="utf-8", errors="ignore").read()
            except OSError:
                continue
            for guid in set(SCRIPT_REF.findall(text)):
                if guid not in have:
                    dangling.setdefault(guid, []).append(
                        os.path.relpath(p, PROJECT))

    for guid, where in sorted(dangling.items()):
        print(f"  {guid}  <- {where[0]}" +
              (f" (+{len(where) - 1} more)" if len(where) > 1 else ""))
    print(f"\n{len(dangling)} dangling GUIDs (baseline is 4)")
    return 1 if len(dangling) > 4 else 0


if __name__ == "__main__":
    sys.exit(main())
```

```csharp
using System;
using UnityEngine;

/// <summary>
/// The settings the player chooses, and the only thing the settings UI edits. Backed by
/// PlayerPrefs under the existing Constants.PP_* keys, so settings saved by older builds
/// are picked up unchanged.
///
/// Main used to read these straight from PlayerPrefs in Start (and owned them from then on),
/// which meant the settings panel could only work in a scene that had a Main. Now Main reads
/// this on Start and re-applies whenever Changed fires, so the same SettingsScreen prefab
/// works in Splash - where there is no Main at all - as in a match.
///
/// Plain static C# on purpose: no MonoBehaviour, no scene, so it is unit-testable.
/// </summary>
public static class GameSettings
{
    public const int MinOvers = 1;
    public const int MaxOvers = 20;

    /// Raised after any value actually changes. Never raised for a set to the same value:
    /// Main re-applies everything on this, and doing so mid-over is visible to the player.
    public static event Action Changed;

    private static bool loaded;
    private static int overs;
    private static float batPower;
    private static float fielderSpeed;
    private static eDifficulty difficulty;
    private static eBattingStyle battingStyle;
    private static eSwingType bowlerType;
    private static bool overlayVisible;

    // ---- Values ---------------------------------------------------------------------------

    public static int Overs
    {
        get { Load(); return overs; }
        set
        {
            Load();
            int clamped = Mathf.Clamp(value, MinOvers, MaxOvers);
            if (clamped == overs) return;
            overs = clamped;
            PlayerPrefs.SetInt(Constants.PP_Overs, clamped);
            Save();
        }
    }

    public static float BatPower
    {
        get { Load(); return batPower; }
        set
        {
            Load();
            if (Mathf.Approximately(value, batPower)) return;
            batPower = value;
            PlayerPrefs.SetFloat(Constants.PP_BatPower, value);
            Save();
        }
    }

    public static float FielderSpeed
    {
        get { Load(); return fielderSpeed; }
        set
        {
            Load();
            if (Mathf.Approximately(value, fielderSpeed)) return;
            fielderSpeed = value;
            PlayerPrefs.SetFloat(Constants.PP_FielderSpeed, value);
            Save();
        }
    }

    public static eDifficulty Difficulty
    {
        get { Load(); return difficulty; }
        set
        {
            Load();
            if (value == difficulty) return;
            difficulty = value;
            PlayerPrefs.SetInt(Constants.PP_Difficulty, (int)value);
            Save();
        }
    }

    public static eBattingStyle BattingStyle
    {
        get { Load(); return battingStyle; }
        set
        {
            Load();
            if (value == battingStyle) return;
            battingStyle = value;
            PlayerPrefs.SetInt(Constants.PP_BattingStyle, (int)value);
            Save();
        }
    }

    public static eSwingType BowlerType
    {
        get { Load(); return bowlerType; }
        set
        {
            Load();
            if (value == bowlerType) return;
            bowlerType = value;
            PlayerPrefs.SetInt(Constants.PP_BowlerType, (int)value);
            Save();
        }
    }

    public static bool OverlayVisible
    {
        get { Load(); return overlayVisible; }
        set
        {
            Load();
            if (value == overlayVisible) return;
            overlayVisible = value;
            PlayerPrefs.SetInt(Constants.PP_Overlay, value ? 1 : 0);
            Save();
        }
    }

    // ---- Persistence ----------------------------------------------------------------------

    private static void Load()
    {
        if (loaded) return;
        loaded = true;   // set first: the reads below must not recurse
        overs = Mathf.Clamp(PlayerPrefs.GetInt(Constants.PP_Overs, 5), MinOvers, MaxOvers);
        batPower = PlayerPrefs.GetFloat(Constants.PP_BatPower, Constants.BatPowerRealistic);
        fielderSpeed = PlayerPrefs.GetFloat(Constants.PP_FielderSpeed, 1f);
        difficulty = (eDifficulty)PlayerPrefs.GetInt(Constants.PP_Difficulty, (int)eDifficulty.Medium);
        battingStyle = (eBattingStyle)PlayerPrefs.GetInt(Constants.PP_BattingStyle, (int)eBattingStyle.RightHanded);
        bowlerType = (eSwingType)PlayerPrefs.GetInt(Constants.PP_BowlerType, (int)eSwingType.Pace);
        overlayVisible = PlayerPrefs.GetInt(Constants.PP_Overlay, 0) == 1;
    }

    private static void Save()
    {
        PlayerPrefs.Save();
        Changed?.Invoke();
    }

    /// Drop the cache and re-read PlayerPrefs. For tests, and for anything that changes
    /// prefs behind this class's back.
    public static void ReloadForTests()
    {
        loaded = false;
        Load();
    }
}
```

```csharp
using System.Collections.Generic;

/// <summary>
/// Which menu screen is showing, and what Back does. Screens are identified by name so this
/// is pure logic with no GameObject references - MenuRoot maps a name to the screen it owns.
///
/// Splash resets to "main"; CricketVR and Nets reset to "pause". Settings is pushed from
/// either, and Pop returns to whoever pushed it, which is what lets one SettingsScreen prefab
/// serve all three scenes.
/// </summary>
public class MenuStack
{
    private readonly List<string> screens = new List<string>();

    /// The screen that should be visible, or null when the menu is closed.
    public string Current => screens.Count > 0 ? screens[screens.Count - 1] : null;

    public bool IsOpen => screens.Count > 0;

    /// Back is offered on everything except the root screen.
    public bool CanGoBack => screens.Count > 1;

    /// Open the menu at its root screen, discarding any previous history.
    public void Reset(string root)
    {
        screens.Clear();
        screens.Add(root);
    }

    /// Show `screen` over the current one. Pushing the screen that is already showing does
    /// nothing, so a double-click does not need two Backs to undo.
    public void Push(string screen)
    {
        if (Current == screen)
            return;
        screens.Add(screen);
    }

    /// Back. At the root this empties the stack, which closes the menu.
    public void Pop()
    {
        if (screens.Count > 0)
            screens.RemoveAt(screens.Count - 1);
    }
}
```

```csharp
using UnityEngine;

/// <summary>
/// The one world-space menu host, used in Splash, CricketVR and Nets. It owns everything the
/// individual panels used to each duplicate: placing itself in front of the player, registering
/// with OpenXRMenuInputModule so the laser works, restoring a panel the player has moved by
/// hand, and switching between screens.
///
/// Splash uses it with MainMenuScreen as the root screen and the backdrop shown; the match
/// scenes use the same prefab with PauseScreen as root, inactive until B is pressed.
///
/// Placement mirrors SettingsPanel/NextBallMenu: a fixed distance ahead of where the player is
/// looking, slightly below eye level, tilted up. The canvas faces -Z, so +Z points away.
/// </summary>
public class MenuRoot : MonoBehaviour
{
    private const float Distance = 1.45f;
    private const float BelowEyes = 0.1f;

    [Tooltip("The child that shows and hides. This component's GameObject stays active.")]
    [SerializeField] private GameObject panel;

    [Tooltip("Screen shown when the menu opens. \"main\" in Splash, \"pause\" in a match.")]
    [SerializeField] private string rootScreen = "main";

    [Tooltip("Every screen this root can show. Order does not matter.")]
    [SerializeField] private MenuScreen[] screens;

    [Tooltip("Optional. Shown only where a backdrop makes sense - Splash.")]
    [SerializeField] private MenuBackdrop backdrop;

    private readonly MenuStack stack = new MenuStack();
    private bool registered;

    public static MenuRoot Instance { get; private set; }

    public bool IsOpen => stack.IsOpen;

    private void Awake()
    {
        Instance = this;
        foreach (MenuScreen screen in screens)
        {
            screen.Root = this;
            screen.gameObject.SetActive(false);
        }
        panel.SetActive(false);
    }

    // ---- Opening and closing ------------------------------------------------------------------

    /// Open at the root screen, placed in front of the player.
    public void Open()
    {
        if (!registered && OpenXRMenuInputModule.Instance != null)
        {
            OpenXRMenuInputModule.RegisterPanel(panel);
            registered = true;
        }
        Place();
        stack.Reset(rootScreen);
        panel.SetActive(true);
        if (backdrop != null)
            backdrop.Show();
        Apply();
    }

    public void Close()
    {
        HideCurrent();
        stack.Reset(null);
        stack.Pop();
        panel.SetActive(false);
        if (backdrop != null)
            backdrop.Hide();
    }

    public void Push(string screen)
    {
        HideCurrent();
        stack.Push(screen);
        Apply();
    }

    /// Back. Popping the root screen closes the menu rather than leaving a blank card.
    public void Back()
    {
        HideCurrent();
        stack.Pop();
        if (!stack.IsOpen)
            Close();
        else
            Apply();
    }

    // ---- Wired in the prefab --------------------------------------------------------------------
    public void OnOpenSettings() => Push("settings");

    // ---- Internals --------------------------------------------------------------------------------

    /// Switch on whichever screen the stack says is current, and tell it to refresh.
    private void Apply()
    {
        string current = stack.Current;
        foreach (MenuScreen screen in screens)
        {
            bool on = screen.ScreenName == current;
            if (screen.gameObject.activeSelf != on)
                screen.gameObject.SetActive(on);
            if (on)
                screen.OnShow();
        }
    }

    private void HideCurrent()
    {
        string current = stack.Current;
        if (current == null)
            return;
        foreach (MenuScreen screen in screens)
            if (screen.ScreenName == current)
                screen.OnHide();
    }

    private void Place()
    {
        Transform head = Camera.main.transform;
        Vector3 forward = Vector3.ProjectOnPlane(head.forward, Vector3.up);
        if (forward.sqrMagnitude < 1e-4f) forward = Vector3.left;
        forward.Normalize();
        panel.transform.SetPositionAndRotation(
            head.position + forward * Distance + Vector3.down * BelowEyes,
            Quaternion.LookRotation(forward, Vector3.up) * Quaternion.Euler(8f, 0f, 0f));
        // Moved by hand before (grip): open where it was left instead.
        if (TryGetComponent(out GrabbablePanel grab))
            grab.Restore();
    }
}
```

```csharp
using System.Collections;
using UnityEngine;
using UnityEngine.SceneManagement;
using UnityEngine.UI;

/// <summary>
/// Fades to black, loads a scene, fades back in. A hard cut between VR scenes is genuinely
/// unpleasant in a headset, and the black also covers the frame or two where XRRigSetup is
/// still looking for a floor-relative tracking origin and the camera sits at the fallback
/// eye height.
///
/// Placed in each scene by the scene builders, on a screen-space overlay canvas that sorts
/// above everything.
/// </summary>
public class SceneFader : MonoBehaviour
{
    private const float FadeSeconds = 0.35f;

    [SerializeField] private Image black;

    private static SceneFader instance;

    private void Awake()
    {
        instance = this;
        if (black != null)
        {
            black.color = new Color(0f, 0f, 0f, 1f);
            black.raycastTarget = false;
        }
    }

    private void Start()
    {
        StartCoroutine(Fade(1f, 0f));
    }

    /// Load `sceneName` behind a fade. Safe to call with no fader in the scene: it falls back
    /// to a plain load rather than failing to change scene at all.
    public static void Load(string sceneName)
    {
        // Pause may have frozen time; a coroutine using scaled time would never advance.
        Time.timeScale = 1f;
        if (instance == null)
        {
            SceneManager.LoadScene(sceneName);
            return;
        }
        instance.StartCoroutine(instance.LoadRoutine(sceneName));
    }

    private IEnumerator LoadRoutine(string sceneName)
    {
        yield return Fade(0f, 1f);
        yield return SceneManager.LoadSceneAsync(sceneName);
    }

    private IEnumerator Fade(float from, float to)
    {
        if (black == null)
            yield break;
        black.raycastTarget = to > from;   // swallow clicks while covering the view
        for (float t = 0f; t < FadeSeconds; t += Time.unscaledDeltaTime)
        {
            float a = Mathf.Lerp(from, to, t / FadeSeconds);
            black.color = new Color(0f, 0f, 0f, a);
            yield return null;
        }
        black.color = new Color(0f, 0f, 0f, to);
        black.raycastTarget = to > 0.99f;
    }
}
```

```csharp
/// track (Docs/AssetSources.md, tier 2). Re-run whenever the stadium changes.
///
/// The HUD, players and debug boards are hidden for the capture: the baseline renders in
/// Docs/Baseline show why - they carry the Distance/Ball Speed board across the sightscreen.
/// </summary>
public static class BackdropBaker
{
    private const string Folder = "Assets/Resources/UI/Backdrops";
    private const string Scene = "Assets/Scenes/CricketVR.unity";
    private const int Width = 2048;
    private const int Height = 1024;

    /// Where each plate is shot from, and which screen uses it.
    private struct Shot
    {
        public string Name;
        public Vector3 Position;
        public Vector3 Euler;
        public float Fov;
    }

    private static readonly Shot[] Shots =
    {
        // High behind the bowler's arm, looking down the pitch - the main menu.
        new Shot { Name = "Backdrop-BowlersEnd", Position = new Vector3(0f, 14f, -34f),
                   Euler = new Vector3(11f, 0f, 0f), Fov = 42f },
        // Square of the wicket, the broadcast side-on - settings.
        new Shot { Name = "Backdrop-SquareLeg", Position = new Vector3(-38f, 12f, 2f),
                   Euler = new Vector3(10f, 78f, 0f), Fov = 40f },
        // Deep midwicket, more crowd in frame - pause.
        new Shot { Name = "Backdrop-DeepMidwicket", Position = new Vector3(-30f, 9f, 26f),
                   Euler = new Vector3(8f, 132f, 0f), Fov = 46f },
    };

    [MenuItem("Tools/CricketVR/Bake Menu Backdrops")]
    public static void Bake()
    {
        if (!EditorSceneManager.SaveCurrentModifiedScenesIfUserWantsTo())
            return;
        Scene open = EditorSceneManager.OpenScene(Scene, OpenSceneMode.Single);
        Directory.CreateDirectory(Folder);

        GameObject[] hidden = HideForCapture();
        var rig = new GameObject("BackdropCamera", typeof(Camera));
        var camera = rig.GetComponent<Camera>();
        camera.clearFlags = CameraClearFlags.Skybox;
        camera.nearClipPlane = 0.3f;
        camera.farClipPlane = 600f;

        foreach (Shot shot in Shots)
        {
            rig.transform.SetPositionAndRotation(shot.Position, Quaternion.Euler(shot.Euler));
            camera.fieldOfView = shot.Fov;
            Texture2D plate = Capture(camera);
            Grade(plate);
            File.WriteAllBytes($"{Folder}/{shot.Name}.png", plate.EncodeToPNG());
            Object.DestroyImmediate(plate);
        }

        Object.DestroyImmediate(rig);
        foreach (GameObject go in hidden)
            if (go != null) go.SetActive(true);

        AssetDatabase.Refresh();
        foreach (Shot shot in Shots)
            ImportAsBackdrop($"{Folder}/{shot.Name}.png");

        EditorSceneManager.OpenScene(Scene, OpenSceneMode.Single);
        Debug.Log($"[BackdropBaker] Baked {Shots.Length} plates to {Folder}. " +
                  "Scene reloaded; nothing in CricketVR was saved.");
        _ = open;
    }

    /// Hide anything that must not appear in a menu backdrop: the HUD and debug boards, the
    /// players, and the bat.
    private static GameObject[] HideForCapture()
    {
        var hide = new System.Collections.Generic.List<GameObject>();
        void HideAll<T>() where T : Component
        {
            foreach (T c in Object.FindObjectsByType<T>(FindObjectsInactive.Exclude,
                                                        FindObjectsSortMode.None))
                if (c.gameObject.activeSelf) { c.gameObject.SetActive(false); hide.Add(c.gameObject); }
        }
        HideAll<HUD>();
        HideAll<Canvas>();
        HideAll<AnimatedBowler>();
        HideAll<AnimatedFielder>();
        HideAll<Bat>();
        return hide.ToArray();
    }

    private static Texture2D Capture(Camera camera)
    {
        var rt = new RenderTexture(Width, Height, 24, RenderTextureFormat.ARGB32)
        {
            antiAliasing = 4
        };
        camera.targetTexture = rt;
        camera.Render();
        RenderTexture previous = RenderTexture.active;
        RenderTexture.active = rt;
        var plate = new Texture2D(Width, Height, TextureFormat.RGBA32, false);
        plate.ReadPixels(new Rect(0, 0, Width, Height), 0, 0);
        plate.Apply();
        RenderTexture.active = previous;
        camera.targetTexture = null;
        rt.Release();
        Object.DestroyImmediate(rt);
        return plate;
    }

    /// The floodlit grade: indigo at the top through magenta to coral at the horizon, over the
    /// render at roughly 45% - the balance chosen in the design mockups. A left-side vignette
    /// darkens where the menu card sits so white text always has something to sit on.
    private static void Grade(Texture2D plate)
    {
        Color top = new Color(0.106f, 0.043f, 0.231f);      // #1B0B3B
        Color mid = new Color(0.357f, 0.118f, 0.549f);      // #5B1E8C
        Color low = new Color(0.761f, 0.153f, 0.557f);      // #C2278E
        Color horizon = new Color(1f, 0.420f, 0.290f);      // #FF6B4A

        Color32[] pixels = plate.GetPixels32();
        for (int y = 0; y < Height; y++)
        {
            // v = 0 at the top of the image. Texture rows run bottom-up.
            float v = 1f - (y / (float)(Height - 1));
            Color tint = v < 0.45f ? Color.Lerp(top, mid, v / 0.45f)
                       : v < 0.78f ? Color.Lerp(mid, low, (v - 0.45f) / 0.33f)
                                   : Color.Lerp(low, horizon, (v - 0.78f) / 0.22f);
            for (int x = 0; x < Width; x++)
            {
                int i = y * Width + x;
                Color src = (Color)pixels[i];
                Color graded = Color.Lerp(src, tint, 0.55f);

                // Vignette: strong on the left where the card sits, light on the right.
                float u = x / (float)(Width - 1);
                float darken = Mathf.Lerp(0.62f, 0f, Mathf.Clamp01(u / 0.55f))
                             + Mathf.Lerp(0f, 0.35f, Mathf.Clamp01((u - 0.7f) / 0.3f));
                graded = Color.Lerp(graded, Color.black, darken);

                graded.a = 1f;
                pixels[i] = graded;
            }
        }
        plate.SetPixels32(pixels);
        plate.Apply();
    }

    private static void ImportAsBackdrop(string path)
    {
        AssetDatabase.ImportAsset(path, ImportAssetOptions.ForceSynchronousImport);
        var importer = (TextureImporter)AssetImporter.GetAtPath(path);
        importer.textureType = TextureImporterType.Sprite;
        importer.spriteImportMode = SpriteImportMode.Single;
        importer.mipmapEnabled = true;
        importer.wrapMode = TextureWrapMode.Clamp;
        importer.filterMode = FilterMode.Bilinear;
        importer.maxTextureSize = 2048;
        var android = new TextureImporterPlatformSettings
        {
            name = "Android",
            overridden = true,
            maxTextureSize = 2048,
            format = TextureImporterFormat.ASTC_6x6,
            compressionQuality = 100,
        };
        importer.SetPlatformTextureSettings(android);
        importer.SaveAndReimport();
    }
}
```

```csharp
/// <summary>
/// Tools > CricketVR > Build Menu Prefabs. Builds the opening-menu prefabs under
/// Assets/Resources/Prefabs/UI, all in the UIStyle look:
///   * MenuRoot   - the world-space host with the screen stack, used in all three scenes;
///   * MainMenuScreen - Quick Match (with overs steppers), Practice in Nets, Settings;
///   * PauseScreen    - Resume, Settings, Main Menu, plus the leave-match confirm row.

/// Tools > CricketVR > Build Player UI, re-parented under MenuRoot by the scene builders.
///
/// Every control is wired with a persistent (saved) listener, so the prefabs work with nothing
/// created or hooked up at runtime.
/// </summary>
public static class MenuPrefabBuilder
{
    private const string PrefabFolder = "Assets/Resources/Prefabs/UI";
    private const float Mm = 0.001f;              // 1 canvas px = 1 mm, as elsewhere
    private const float MenuWidth = 760f;
    private const float BackdropWidth = 2400f;
    private const float BackdropHeight = 1200f;

    [MenuItem("Tools/CricketVR/Build Menu Prefabs")]
    public static void Build()
    {
        Directory.CreateDirectory(PrefabFolder);
        UIStyle.EnsureSprites();

        GameObject root = BuildMenuRoot();
        PrefabUtility.SaveAsPrefabAsset(root, $"{PrefabFolder}/MenuRoot.prefab");
        Object.DestroyImmediate(root);

        AssetDatabase.SaveAssets();
        Debug.Log("[MenuPrefabBuilder] MenuRoot (with MainMenuScreen and PauseScreen) built at "
                  + PrefabFolder + "/MenuRoot.prefab");
    }

    private static GameObject BuildMenuRoot()
    {
        var root = new GameObject("MenuRoot");
        MenuRoot menu = root.AddComponent<MenuRoot>();
        root.AddComponent<GrabbablePanel>();

        GameObject panel = WorldPanelBuilder.Canvas(root, MenuWidth, Mm, true);

        // Backdrop first, so it sorts behind the card.
        MenuBackdrop backdrop = BuildBackdrop(panel.transform);

        // The card the screens live in.
        WorldPanelBuilder.MakeCard(panel, UIStyle.Pad, UIStyle.SectionGap);
        WorldPanelBuilder.FitContent(panel, false);

        MainMenuScreen main = BuildMainMenu(panel.transform);
        PauseScreen pause = BuildPause(panel.transform);
        MenuScreen settingsPlaceholder = null;   // filled by the scene builders

        var so = new SerializedObject(menu);
        so.FindProperty("panel").objectReferenceValue = panel;
        so.FindProperty("rootScreen").stringValue = "main";
        so.FindProperty("backdrop").objectReferenceValue = backdrop;
        SerializedProperty screens = so.FindProperty("screens");
        screens.arraySize = 2;
        screens.GetArrayElementAtIndex(0).objectReferenceValue = main;
        screens.GetArrayElementAtIndex(1).objectReferenceValue = pause;
        so.ApplyModifiedProperties();
        _ = settingsPlaceholder;

        return root;
    }

    private static MenuBackdrop BuildBackdrop(Transform parent)
    {
        var go = new GameObject("Backdrop", typeof(RectTransform), typeof(Image),
                                typeof(MenuBackdrop));
        go.transform.SetParent(parent, false);
        var rect = go.GetComponent<RectTransform>();
        rect.sizeDelta = new Vector2(BackdropWidth, BackdropHeight);
        rect.anchoredPosition = Vector2.zero;
        var image = go.GetComponent<Image>();
        image.raycastTarget = false;
        image.preserveAspect = true;
        var backdrop = go.GetComponent<MenuBackdrop>();
        var so = new SerializedObject(backdrop);
        so.FindProperty("image").objectReferenceValue = image;
        so.FindProperty("defaultPlate").stringValue = "Backdrop-BowlersEnd";
        so.ApplyModifiedProperties();
        return backdrop;
    }

    private static MainMenuScreen BuildMainMenu(Transform parent)

        Transform column = Screen(parent, "MainMenuScreen", out GameObject go);
        MainMenuScreen screen = go.AddComponent<MainMenuScreen>();
        SetScreenName(screen, "main");

        WorldPanelBuilder.Text(column, "CricketVR", UIStyle.TitleSize, FontStyles.Bold,
                               UIStyle.Text, 56f);
        WorldPanelBuilder.Text(column, "Step in and face the over",
                               UIStyle.HintSize, FontStyles.Normal, UIStyle.TextMuted, 28f);
        UIControls.Divider(column);

        // Quick Match, with the overs stepper on the row itself.
        Transform row = WorldPanelBuilder.Column(column, false, UIStyle.Unit);
        WorldPanelBuilder.NoForceExpand(row);
        Button play = UIControls.ActionButton(row, "Quick Match", null, true, 420f);
        play.colors = UIStyle.MenuColors(true);
        UnityEventTools.AddPersistentListener(play.onClick, screen.OnQuickMatch);

        Button fewer = UIControls.ActionButton(row, "‹", null, false, 72f);
        UnityEventTools.AddPersistentListener(fewer.onClick, screen.OnFewerOvers);
        TextMeshProUGUI overs = WorldPanelBuilder.Line(row, "5 overs", UIStyle.LabelSize,
                                                       FontStyles.Bold, UIStyle.Text,

        Button more = UIControls.ActionButton(row, "›", null, false, 72f);

        so.FindProperty("oversLabel").objectReferenceValue = overs;
        so.ApplyModifiedProperties();

    private static PauseScreen BuildPause(Transform parent)
    {
        Transform column = Screen(parent, "PauseScreen", out GameObject go);
        PauseScreen screen = go.AddComponent<PauseScreen>();
        SetScreenName(screen, "pause");

        WorldPanelBuilder.Text(column, "Paused", UIStyle.TitleSize, FontStyles.Bold,
                               UIStyle.Text, 56f);
        UIControls.Divider(column);

        Transform actions = WorldPanelBuilder.Column(column, true, UIStyle.Gap);
        Button resume = UIControls.ActionButton(actions, "Resume", null, true);
        resume.colors = UIStyle.MenuColors(true);
        UnityEventTools.AddPersistentListener(resume.onClick, screen.OnResume);
        Button settings = UIControls.ActionButton(actions, "Settings", null, false);
        UnityEventTools.AddPersistentListener(settings.onClick, screen.OnSettings);
        Button leave = UIControls.ActionButton(actions, "Main Menu", null, false);
        UnityEventTools.AddPersistentListener(leave.onClick, screen.OnMainMenu);

        // The confirm row, hidden until Main Menu is pressed.
        Transform confirm = WorldPanelBuilder.Column(column, true, UIStyle.Gap);
        WorldPanelBuilder.Text(confirm, "Leave match? Your score will be lost.",
                               UIStyle.LabelSize, FontStyles.Normal, UIStyle.Text, 40f);

        yes.colors = UIStyle.MenuColors(false);

        var so = new SerializedObject(screen);

        so.FindProperty("confirmRow").objectReferenceValue = confirm.gameObject;
        so.FindProperty("actionRow").objectReferenceValue = actions.gameObject;

    }

    private static Transform Screen(Transform parent, string name, out GameObject go)

    {
        var so = new SerializedObject(screen);
        so.FindProperty("screenName").stringValue = name;
        so.ApplyModifiedProperties();
    }
```

```csharp
using UnityEditor;
using UnityEditor.SceneManagement;
using UnityEngine;
using UnityEngine.SceneManagement;

/// <summary>
/// Tools > CricketVR > Build Splash Scene. Splash.unity has only ever held a camera and a
/// light; this fills it in as the game's front door - an XR rig with a floor-relative origin,
/// the laser pointer and event system, and the MenuRoot prefab opened on the main menu.
///
/// It also puts the build list in order: Splash must be index 0 to be the launch scene, with
/// CricketVR and Nets enabled so the menu can load them.
/// </summary>
public static class SplashSceneBuilder
{
    private const string SplashPath = "Assets/Scenes/Splash.unity";
    private const string CricketPath = "Assets/Scenes/CricketVR.unity";
    private const string NetsPath = "Assets/Scenes/Nets.unity";
    private const string MenuRootPrefab = "Assets/Resources/Prefabs/UI/MenuRoot.prefab";

    [MenuItem("Tools/CricketVR/Build Splash Scene")]
    public static void Build()
    {
        if (!EditorSceneManager.SaveCurrentModifiedScenesIfUserWantsTo())
            return;
        Scene scene = EditorSceneManager.OpenScene(SplashPath, OpenSceneMode.Single);

        SetUpRig();
        SetUpMenu();
        SetUpBuildList();

        EditorSceneManager.MarkSceneDirty(scene);
        EditorSceneManager.SaveScene(scene);
        AssetDatabase.SaveAssets();
        Debug.Log("[SplashSceneBuilder] Splash built: XR rig, pointer, MenuRoot on the main " +
                  "menu. Build list set with Splash at index 0.");
    }

    /// The camera under a rig root at y = 0, with XRRigSetup so the player gets their own
    /// eye height from a floor-relative tracking origin - the same arrangement as the match
    /// scenes, so the menu sits at the right height.
    private static void SetUpRig()
    {
        Camera camera = Camera.main;
        if (camera == null)
        {
            var go = new GameObject("Main Camera", typeof(Camera), typeof(AudioListener));
            go.tag = "MainCamera";
            camera = go.GetComponent<Camera>();
        }
        Transform rig = camera.transform.parent;
        if (rig == null || rig.GetComponent<XRRigSetup>() == null)
        {
            var rigGo = GameObject.Find("XRRig") ?? new GameObject("XRRig");
            rigGo.transform.position = Vector3.zero;
            camera.transform.SetParent(rigGo.transform, false);
            rig = rigGo.transform;
        }
        if (rig.GetComponent<XRRigSetup>() == null)
            rig.gameObject.AddComponent<XRRigSetup>();
        camera.clearFlags = CameraClearFlags.SolidColor;
        camera.backgroundColor = new Color(0.043f, 0.024f, 0.094f);   // matches the grade
        camera.nearClipPlane = 0.05f;
    }

    /// The pointer and event system come from the proven path in CricketVRSceneBuilder rather
    /// than a second copy here.
    private static void SetUpMenu()
    {
        CricketVRSceneBuilder.SetUpPointer();

        MenuRoot existing = Object.FindFirstObjectByType<MenuRoot>(FindObjectsInactive.Include);
        if (existing == null)
        {
            var prefab = AssetDatabase.LoadAssetAtPath<GameObject>(MenuRootPrefab);
            if (prefab == null)
            {
                Debug.LogError("[SplashSceneBuilder] No MenuRoot prefab - run " +
                               "Tools > CricketVR > Build Menu Prefabs first.");
                return;
            }
            var instance = (GameObject)PrefabUtility.InstantiatePrefab(prefab);
            instance.name = "MenuRoot";
            existing = instance.GetComponent<MenuRoot>();
        }

        // Splash opens straight onto the menu; nothing else here would open it.
        if (existing.GetComponent<SplashMenuOpener>() == null)
            existing.gameObject.AddComponent<SplashMenuOpener>();
    }

    private static void SetUpBuildList()
    {
        var scenes = new System.Collections.Generic.List<EditorBuildSettingsScene>
        {
            new EditorBuildSettingsScene(SplashPath, true),
            new EditorBuildSettingsScene(CricketPath, true),
            new EditorBuildSettingsScene(NetsPath, true),
        };
        // Keep the existing disabled Oculus sample entries after ours, still disabled.
        foreach (EditorBuildSettingsScene s in EditorBuildSettings.scenes)
        {
            string p = s.path;
            if (p == SplashPath || p == CricketPath || p == NetsPath)
                continue;
            scenes.Add(new EditorBuildSettingsScene(p, false));
        }
        EditorBuildSettings.scenes = scenes.ToArray();
    }
}
```

## Task 13: Mouse input in the editor

The menu must be usable in editor play mode with a mouse, with no headset attached — that is
how most iteration on it will happen.

`Assets/Resources/Input/MenuUIActions.inputactions` already binds `Point` to `<Mouse>/position`
and `Click` to `<Mouse>/leftButton`, and `OpenXRMenuInputModule.RegisterPanel` already sets
`canvas.worldCamera`, so a world-space `GraphicRaycaster` should convert mouse position into
hits. This task proves that end to end and fixes the two places it is likely to fall down.

**Files:**
- Modify: `Assets/Scripts/OpenXRMenuInputModule.cs`

- [ ] **Step 1: Test it as-is before changing anything**

Open `Assets/Scenes/Splash.unity` with no headset connected, press Play, and click the menu
buttons with the mouse in the Game view.

Record which of these is true:
- (a) Buttons highlight on hover and respond to clicks — mouse already works, skip to Step 4.
- (b) Nothing highlights or responds — continue to Step 2.

- [ ] **Step 2: Keep the input module alive without a tracked hand**

`OpenXRMenuInputModule.Update` enables the module on `AnyPanelOpen() && Application.isFocused`,
which does not depend on XR, so this should already be satisfied. Confirm by adding a temporary
log and watching the Console:

```csharp
        bool open = AnyPanelOpen() && Application.isFocused;
        Debug.Log($"[menu] panels open={open} module={inputModule.enabled}");
```

Expected: `open=True` once the menu is showing. If it is `False`, the panel was never
registered — check that `MenuRoot.Open` reached `OpenXRMenuInputModule.RegisterPanel`, which
requires `OpenXRMenuInputModule.Instance` to be non-null, i.e. the pointer to exist in the
scene. Remove the log once diagnosed.

- [ ] **Step 3: Make the canvas camera survive a missing `Camera.main`**

`RegisterPanel` assigns `canvas.worldCamera = Camera.main` once, at registration. If the menu
registers before the camera is tagged `MainCamera`, the canvas keeps a null camera and a
world-space `GraphicRaycaster` silently returns no hits for the mouse.

In `Assets/Scripts/OpenXRMenuInputModule.cs`, in `Update`, after the `xrTrackingOrigin` line,
add:

```csharp
        // World-space GraphicRaycaster needs a camera to turn a mouse position into a ray.
        // Re-assert it each frame: at registration Camera.main can still be null, and in the
        // editor there is no tracked hand to fall back on.
        if (Camera.main != null)
            foreach (GameObject p in panels)
            {
                if (p == null) continue;
                foreach (var canvas in p.GetComponentsInChildren<Canvas>(true))
                    if (canvas.worldCamera == null)
                        canvas.worldCamera = Camera.main;
            }
```

- [ ] **Step 4: Confirm the beam does not fight the mouse**

`LateUpdate` hides the beam when no hand is tracked (`visible` is false), and returns early.
That path must not disable `inputModule`, or the mouse would stop working whenever the
controllers are absent.

Run: `grep -n "inputModule.enabled" Assets/Scripts/OpenXRMenuInputModule.cs`
Expected: assignments only in `Awake`, `Update` and `OnDisable` — none inside `LateUpdate`.
If `LateUpdate` disables it, remove that line: the beam's visibility and the module's enabled
state are separate concerns.

   Stay. All respond.
3. `Nets.unity` — press `/`, click Main Menu. Leaves with no confirm.
